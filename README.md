# Święta Łucja

Horror w pierwszej osobie w przeglądarce (Three.js). Rok 2004, opuszczony szpital psychiatryczny, w którym zaginęła twoja siostra Ola. Wszystko widzisz przez obiektyw starej kamery VHS.

## Jak zagrać

Otwórz `index.html` w Chrome, Edge albo Firefoksie (dwuklik wystarczy). Przy pierwszym uruchomieniu potrzebny jest internet, bo biblioteka Three.js wczytuje się z CDN.

Graj w słuchawkach i po ciemku.

## Sterowanie

| Klawisz | Akcja |
|---|---|
| WASD + mysz | ruch, rozglądanie się |
| Shift | bieg |
| C | kucanie |
| F | latarka |
| R | potrząśnij latarką |
| E | podnieś / otwórz / schowaj się |
| Tab | dziennik i cel |
| Esc | pauza |
| Spacja (przytrzymaj) | pomiń scenkę; Shift+Spacja: całe intro |

## Ustawienia

Czułość myszy, głośność, intensywność VHS, jasność oraz jakość grafiki (Niska / Średnia / Wysoka).

## Zrzuty ekranu

Folder [`screenshots/`](screenshots/) — potwór na suficie, kryjówki, szuflady, jumpscare'y, poziomy grafiki.
